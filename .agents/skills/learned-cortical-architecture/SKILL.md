## Regole & Sintesi Generale
Cortical è un'architettura ibrida Tree/Graph progettata per sistemi agenti scalabili e sicuri. Integra un "Second Brain" basato su indici deterministici Merkle con verifica fattuale a due stadi tramite modelli NLI. Il framework supporta multi-tenancy via RBAC e ACL, gestendo dati strutturati e non in parallelo. Include un CLI guidato dal voice engine che attiva riflessi immediati (System 1) o decisionali complessi (System 2). L'architettura modulare garantisce compatibilità con server MCP per la scoperta degli strumenti e include suite di test integrate per la validazione dei componenti, offrendo una soluzione versatile per sviluppatori e architetti di sistemi.

## Cortical Architecture

**Core Components**:
1. **Merkle/Macro-Graph Second Brain**:
   - Parallel deterministic indexing with Merkle hashing
   - 2-stage citation fact-checking via NLI models
2. **Multi-tenancy Framework**:
   - Role-based access control (RBAC)
   - Access control lists (ACL)
3. **Hybrid Tree/Graph Architecture**:
   - Scalable for both structured and unstructured data
   - Optimized for parallel processing
4. **Voice-Driven CLI**:
   - System 1 reflexes for immediate execution
   - System 2 reflexes for complex decision-making
