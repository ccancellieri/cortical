## Cortical Architecture

**Core Components**:
1. **Merkle/Macro-Graph Second Brain**:
   - Parallel deterministic indexing with Merkle hashing
   - 2-stage citation fact-checking via NLI models
2. **Multi-tenancy Framework**:
   - Role-based access control (RBAC)
   - Access control lists (ACL)
3. **Hybrid Tree/Graph Architecture**:
   - Scalable for both structured and unstructured data
   - Optimized for parallel processing
4. **Voice-Driven CLI**:
   - System 1 reflexes for immediate execution
   - System 2 reflexes for complex decision-making

**Technical Specifications**:
- Supports dual-path voice engine
- Adaptive permission gate for secure access
- Integrated test suites for component validation
- Compatibility with MCP servers for tool discovery
