## Cortical Quickstart

**Overview**:
Cortical's quickstart includes `setup.sh` for hardware profiling, wiki navigation, and test suites. Key features:
- Parallel deterministic indexing with Merkle hashing
- 2-stage citation fact-checking via NLI models
- Multi-tenancy with RBAC/ACL
- Hybrid tree/graph architecture for scalability
- Voice-driven CLI with System 1/2 reflexes

**Getting Started**:
1. Run `./setup.sh` for hardware profiling
2. Navigate the MCP wiki for architecture details
3. Execute test suites to validate system components

**Target Audience**:
Developers, researchers, and system architects needing scalable, secure agentic systems.
