1. Hardware Preflight & Variable-Quantization Models

Run cortical doctor and cortical models recommend to inspect RAM/VRAM across macOS, Linux & Windows (including Tier 1A 16 GB RAM + 4 GB VRAM hybrids and Tier 1B 16 GB unified running 27B dynamic 4-bit XXS at 8.1 GB). Add custom models in Settings or via cortical models add.

2. 8-Harness Sync & Best-of-Breed Composition

Run cortical sync --dry-run then cortical sync to configure Serena LSP, RTK shell compression, PinchTab/Playwright snapshots, context-mode, optional HTTP Router, and shared rules across Antigravity, pi, OpenCode, OpenClaw, Codex, Claude Code, DeepSeek Harness (dsh) & Unsloth Studio with timestamped backups and --rollback.

3. Dynamic Privacy Vault (`auto` | `fail_closed` | `fail_open`) & TOON

Ingest sensitive docs via Dashboard or cortical ingest file.docx --policy auto. Sensitive items resolve to fail_closed and expose clean cortical://private/<alias> MCP resources + auto-sized memory without pasting files into cloud chats. Use cortical compress for lossless TOON compression.
