Core Architecture (6 Zero-Server Modules)

    

      

        
1. cortical-wiki-mcp

        
Pure Python + SQLite FTS5 4-tier Merkle Tree (light, medium, high, max), Episode Macro-Graph, relational RBAC, and native MCP resources & prompts. Zero Docker or vector-DB bloat.

      

      

        
2. Multi-Model Local Offload Loops

        
Chains pluggable local runners (Ollama, llama.cpp, mlx-lm, OpenAI-compatible) across small routers, medium analysts, and heavy reviewers offline at 0 cloud tokens.

      

      

        
3. Privacy Sanitizer & @private: Gate

        
Strips OOXML/PDF binary metadata, pseudonymizes custom terms and IDs locally, generates harness ignore files, and enforces per-profile cloud egress gates.

      

      

        
4. 200k Dynamic Context Auto-Scaler

        
Auto-discovers loaded models (/api/ps, /api/show) or custom providers and scales num_ctx to live RAM headroom (vm_stat//proc/meminfo).

      

      

        
5. Cortical Skill Engine

        
Manages portable SKILL.md playbooks, compiles and consolidates knowledge-linked procedural skills via Jaccard similarity + local LLM, and tracks verified usage.

      

      

        
6. Zero-Token Analytics & Permission Gate

        
Evaluates shell commands deterministically in <1 ms and generates local offline static dashboards (html/wiki.html, html/token_report.html, html/settings.html).

How to Install & Connect Across Coding Agents

    

      
      
      
      
      
    

    
git clone https://github.com/ccancellieri/cortical.git
cd cortical
python3 -m venv .venv
.venv/bin/pip install --no-deps -e .
# Pure Python 3.10+ stdlib only — zero external runtime dependencies required

    
{
  "mcpServers": {
    "cortical-wiki": {
      "command": "python3",
      "args": ["-m", "cortical.wiki.mcp_server"],
      "env": {
        "PYTHONPATH": "/path/to/cortical/src",
        "CORTICAL_WIKI_DB": "/path/to/cortical/.cortical_data/wiki.db"
      }
    }
  }
}

    
claude mcp add cortical-wiki \
  -e PYTHONPATH=/path/to/cortical/src \
  -e CORTICAL_WIKI_DB=/path/to/cortical/.cortical_data/wiki.db \
  -- python3 -m cortical.wiki.mcp_server

    
# ~/.codex/config.toml
[mcp_servers.cortical-wiki]
command = "python3"
args = ["-m", "cortical.wiki.mcp_server"]

[mcp_servers.cortical-wiki.env]
PYTHONPATH = "/path/to/cortical/src"
CORTICAL_WIKI_DB = "/path/to/cortical/.cortical_data/wiki.db"

    
# pi package (.pi/extensions + .agents/skills)
pi --package /path/to/cortical

# OpenCode: copy opencode.json & .agents/skills/* into your project
# Zed (~/.config/zed/settings.json): add context_servers.cortical-wiki


    
How to Use, Reproduce Benchmarks & Run Tests

    
# 1. Run the full offline test suite (39 unit tests, zero external deps)
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q

# 2. Reproduce core Merkle crawl, token reduction & Permission Gate benchmarks
PYTHONPATH=src .venv/bin/python scripts/benchmark.py

# 3. Reproduce multi-model local offload loop benchmark (requires local Ollama)
PYTHONPATH=src .venv/bin/python scripts/benchmark_local_offload.py --tmp

# 4. Index a codebase & run a 3-model local offload prompt
PYTHONPATH=src .venv/bin/python -m cortical.cli --db .cortical_data/wiki.db crawl .
PYTHONPATH=src .venv/bin/python -m cortical.cli --db .cortical_data/wiki.db local-loop \
  "Summarize @wiki:/src/cortical/context_window.py /tier:l1" --loops 3

# 5. Sanitize a sensitive document offline
PYTHONPATH=src .venv/bin/python -m cortical.cli sanitize ./document.docx --profile medium

# 6. Export private local dashboards (saved on disk, never uploaded)
PYTHONPATH=src .venv/bin/python -m cortical.cli --db .cortical_data/wiki.db wiki-dashboard --output html/wiki.html
PYTHONPATH=src .venv/bin/python -m cortical.cli --db .cortical_data/wiki.db token-report --html html/token_report.html
PYTHONPATH=src .venv/bin/python -m cortical.cli settings-dashboard --output html/settings.html
