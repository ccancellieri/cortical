🚀 Safe 4-Step Quickstart (Preview First with --dry-run + Instant --rollback)

Cortical never touches harness files silently. Benchmark, diagnose, preview the exact diff, and apply with an automatic rollback snapshot.

git clone https://github.com/ccancellieri/cortical.git
cd cortical && ./install.sh

# 1. Verify lossless TOON, Zero-LLM Privacy Vault & 7-tool MCP
.venv/bin/cortical bench --compare

# 2. Inspect OS/RAM/VRAM tier, Tier-1 Stdlib & detected runners
.venv/bin/cortical doctor

# 3. Preview exact harness diffs FIRST (modifies 0 files)
.venv/bin/cortical sync --dry-run

# 4. Apply with timestamped backup (undo anytime via --rollback)
.venv/bin/cortical sync
# Undo anytime: .venv/bin/cortical sync --rollback <backup_id>
