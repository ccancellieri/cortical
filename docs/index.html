Core Architecture (6 Zero-Dependency Packages + Lean MCP)

    

      

        
1. Hardware Preflight & Model Builder

        
Inspects macOS/Linux/Windows RAM, discrete VRAM, unified memory, and Ollama models via cortical doctor & cortical models. Supports Unsloth variable 4-bit XXS (8.1 GB) + custom user models.

      

      

        
2. OSS Composer & 8-Harness Sync

        
Idempotently configures Serena, RTK, PinchTab/Playwright, and optional HTTP routers across antigravity, pi, opencode, openclaw, codex, claude-code, dsh, and unsloth-studio.

      

      

        
3. Dynamic Privacy Vault (Channels 1–3)

        
Strips OOXML/PDF metadata, runs dynamic auto | fail_closed | fail_open classification + optional local JSON NER, serves cortical://private/<alias>, and intercepts raw prompt uploads on verified harnesses.

      

      

        
4. Lossless Multi-Format TOON Engine

        
Deterministic tabular serialization + XML/YAML/ANSI log compaction with a >=10% saving guard vs compact JSON and auto-sized <=15% num_ctx memory budgets.

      

      

        
5. Lean 5-Tool MCP Server

        
Zero-daemon stdio JSON-RPC server (cortical_vault_read, cortical_ingest_private, cortical_compress, cortical_doctor_status, cortical_local_offload) plus native resources & prompts.

      

      

        
6. Auto-Tuner, ROI & Static UI

        
Zero-cloud-token Auto-Tuner (cortical tune), comparative benchmarks (cortical bench --compare), ROI metrics (cortical roi), and offline static HTML dashboard (docs/settings.html).

Install & Sync Across 8 Harnesses

    

      
      
      
      
      
    

    
git clone https://github.com/ccancellieri/cortical.git
cd cortical
python3 -m venv .venv
.venv/bin/pip install --no-deps -e .
PYTHONPATH=src .venv/bin/python -m cortical.cli doctor
PYTHONPATH=src .venv/bin/python -m cortical.cli sync --dry-run

    
{
  "mcpServers": {
    "cortical": {
      "command": "python3",
      "args": ["-m", "cortical.mcp_server"],
      "env": {
        "PYTHONPATH": "/path/to/cortical/src",
        "CORTICAL_VAULT_DB": "/path/to/cortical/.cortical_data/vault.db"
      }
    }
  }
}

    
claude mcp add cortical \
  -e PYTHONPATH=/path/to/cortical/src \
  -e CORTICAL_VAULT_DB=/path/to/cortical/.cortical_data/vault.db \
  -- python3 -m cortical.mcp_server

    
# OpenAI Codex (~/.codex/config.toml) + DeepSeek Harness (dsh ~/.dsh/settings.yaml)
PYTHONPATH=src .venv/bin/python -m cortical.cli sync --harness codex,dsh

    
# pi package (Channel 3 pre-send interceptor + skills)
pi --package /path/to/cortical

# Configure Unsloth variable-quant 27B & sync Unsloth Studio
PYTHONPATH=src .venv/bin/python -m cortical.cli models add qwen3.8:27b-q4_xxs --mem 8.1 --ctx 32768 --variable
PYTHONPATH=src .venv/bin/python -m cortical.cli sync --harness pi,unsloth-studio


    
Reproduce Benchmarks & Run Offline Tests

    
# 1. Run full offline unittest suite (zero external dependencies)
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q

# 2. Run before-vs-after comparative benchmark
PYTHONPATH=src .venv/bin/python -m cortical.cli bench --compare
PYTHONPATH=src .venv/bin/python scripts/benchmark.py

# 3. Hardware preflight & variable-quant model recommendations
PYTHONPATH=src .venv/bin/python -m cortical.cli doctor
PYTHONPATH=src .venv/bin/python -m cortical.cli models recommend

# 4. Ingest & compress offline, tune settings, and export local dashboard
PYTHONPATH=src .venv/bin/python -m cortical.cli ingest ./notes.md --policy auto --profile medium
PYTHONPATH=src .venv/bin/python -m cortical.cli tune
PYTHONPATH=src .venv/bin/python -m cortical.cli dashboard --out-dir html
