Core Plug-and-Play Modules (Zero-Server, Zero Vector-DB Bloat)

1. cortical-wiki-mcp

Pure Python + SQLite FTS5 4-tier Merkle Tree (light ~50 tok, medium ~250 tok, high ~1000 tok, max) + Episode Macro-Graph + relational RBAC + native MCP resources & prompts. Zero Docker or daemon bloat.

2. Multi-Model Local Offload Loops

Chains fast local models via Ollama / llama.cpp / mlx-lm (e.g. qwen2.5:1.5b router → qwen3.5:9b-q3_k_xl analyst → qwen3:8b reviewer) to solve tasks offline and distill insights without burning cloud tokens.

3. Local Privacy Sanitizer & @private: Gate

Strips OOXML/PDF metadata, pseudonymizes custom terms & IDs ([EMAIL_1], [CUSTOM_1]), protects private vaults with harness ignore rules, and resolves @private: / cortical://private/... policies before cloud egress.

4. Pluggable 200k Context Auto-Scaler

Auto-discovers loaded local models (/api/ps, /api/show) and dynamically sizes num_ctx to live RAM headroom (vm_stat//proc/meminfo) up to 200k—preventing silent 4096 truncation and swap thrashing.

5. Cortical Skill Engine

Maintains standard SKILL.md playbooks (cortical-token-saver, second-brain-3plus1-workflow), consolidates recurring workflows into knowledge-linked learned-* skills, and tracks real usage without skill bloat.

6. Zero-Token ROI & Permission Gate

Parses remote cloud transcripts (mtime+size cached in ~99 ms) alongside local multi-model runs and 3+1 compression savings at 0 cloud tokens, paired with sub-millisecond bash risk scoring.
