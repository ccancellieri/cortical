# Cortical — Scoped AI Context (`src/.ai_context.md`)

1. **Zero Heavy External Runtime Dependencies:** Keep core Python packages (`hardware`, `compression`, `privacy`, `composers`, `harnesses`, `analytics`, `config`, `mcp_server`, `cli`) strictly on Python 3.10+ stdlib (`sqlite3`, `json`, `urllib.request`, `subprocess`, `shutil`, `zipfile`).
2. **Zero-Server by Default:** No daemon or open localhost port unless explicitly invoked (`serve-mcp` or optional HTTP router).
3. **Fixture-Driven Testing:** All external hardware probes, Ollama/HF pulls, and LLM NER calls use deterministic fixtures/injectable functions in `.venv` for offline unit tests.
4. **3-Channel Privacy Vault + Lossless TOON:** Dynamic `auto` | `fail_closed` | `fail_open` ingestion, `>=10%` TOON compression guard, `<=15% num_ctx` memory budget, and Channel 3 pre-send interception strictly on verified harnesses.
