# Cortical — Scoped AI Context (`src/.ai_context.md`)

1. **Zero Heavy External Runtime Dependencies:** Keep core Python modules (`wiki`, `permissions`, `hardware`, `voice`) built on Python 3.10+ stdlib (`sqlite3`, `concurrent.futures`, `hashlib`, `urllib.request`, `subprocess`) so `cortical` installs instantaneously on constrained Linux laptops and macOS machines without C-extension build failures.
2. **Fixture-Driven Testing:** All external LLM/NLI/STT/TTS calls accept injectable client functions or JSON fixture paths (`tests/fixtures/*.json`) for deterministic, zero-token unit tests.
3. **4-Tier Merkle + Macro-Graph Second Brain:**
   - Tiers: `light` (~50 tokens), `medium` (~250 tokens), `high` (~1000 tokens), `max` (full raw content).
   - Relational RBAC (`tenant_id`, `workspace_id`, `principal_id`) enforced in SQL `WHERE` clauses before retrieval.
   - Macro-Graph (`task_episodes`, `macro_edges`) tracks high-level task outcomes and links them to Merkle subtree roots.
